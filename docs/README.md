# ZERO FEAR – Day 3 Technical Documentation

This folder contains the Day 3 architecture and technical planning documents for the ZERO FEAR project.

## Documents

1. `system-architecture-diagram.md` – overall system architecture and data flow.
2. `frontend-architecture.md` – React Native / Expo application structure.
3. `backend-architecture.md` – Django REST Framework backend structure.
4. `database-design.md` – initial database entities and relationships.
5. `api-specification.md` – proposed REST API endpoints and conventions.
6. `authentication-and-security.md` – authentication, authorization and security plan.
7. `ai-scanner-workflow.md` – dashboard image scanning and confirmation workflow.
8. `external-integrations.md` – external services and integration priorities.
9. `technical-decisions.md` – consolidated architecture and technology decisions.

## Agreed Technology Stack

- **Mobile:** React Native + Expo + TypeScript
- **Backend:** Python + Django + Django REST Framework
- **Database:** PostgreSQL + PostGIS
- **AI:** Vision-capable API accessed through Django
- **Development:** Google Antigravity, Git, GitHub and Android Studio

## Scope Note

These documents describe the proposed architecture for the ZERO FEAR MVP.

Provider choices and implementation details may be refined during development.

The initial MVP prioritizes:

- Authentication.
- Vehicle management.
- Dashboard readings.
- AI scanner prototype.
- Reading history.
- Basic insights.
