# ZERO FEAR – MVP Scope

## 1. MVP Objective

Develop an initial usable version of ZERO FEAR for Sri Lankan EV owners.

The MVP should demonstrate the core value of personal EV intelligence, vehicle management and EV journey planning.

## 2. Core MVP Modules

### 2.1 User Authentication
- User registration.
- Login.
- Account management.

### 2.2 Vehicle Management
- Register an EV.
- Select manufacturer, model and variant.
- Manage registered vehicles.
- Select an active vehicle.

### 2.3 AI Dashboard Scanner
- Capture dashboard photographs.
- Extract battery percentage.
- Extract displayed remaining range.
- Extract odometer reading where visible.
- Allow users to correct extracted values.
- Save confirmed readings.

### 2.4 Vehicle Insights
- Dashboard reading history.
- Recorded trip information.
- Battery consumption observations.
- Basic efficiency calculations where sufficient data is available.

### 2.5 Charging Discovery
- Charging station map.
- Station details.
- Connector information.
- Charging power.
- Pricing and availability where reliable data is available.

### 2.6 EV Trip Planning
- Starting location and destination.
- Vehicle selection.
- Current battery input.
- Route alternatives.
- Estimated arrival battery.
- Recommended charging stops.

### 2.7 EV Marketplace
- Browse EV listings.
- Search and filters.
- View listing details.

## 3. Features Requiring Further Development

The following are potential future capabilities:

- Advanced battery analytics.
- Personalised energy prediction.
- Rewards and challenges.
- Community charging assistance.
- Advanced AI assistant.
- Marketplace seller management.
- Emergency charging support.

## 4. MVP Priorities

The initial implementation should prioritise:

1. Authentication.
2. Vehicle registration.
3. Dashboard scanning and confirmation.
4. Vehicle reading history.
5. Charging discovery.
6. Basic battery-aware trip planning.

Other modules can be developed incrementally.

## 5. Important Data Principles

- AI-extracted readings remain pending until confirmed.
- Displayed range must not be treated as actual battery capacity.
- Estimated predictions must be labelled.
- Vehicle specifications should come from verified sources.
- Charging availability should only be displayed as live when supported by reliable data.

## 6. MVP Limitations

The MVP is an initial product release. It will not initially provide direct integration with every EV manufacturer's vehicle systems or guarantee real-time charging availability across all stations.
