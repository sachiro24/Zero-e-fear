# ZERO FEAR – UI/UX Design System

## 1. Design Vision

ZERO FEAR follows a futuristic EV technology design direction.

The interface should communicate intelligence, confidence, simplicity and modern electric mobility.

## 2. Colour Palette

## 3. Typography

Primary typeface: Inter.

Typography should provide:
- Clear readability.
- Consistent heading hierarchy.
- Easy-to-read numerical values.
- Consistent labels and descriptions.

## 4. Themes

The application will support:

### Dark Theme
The primary design theme, using dark navy surfaces and electric green highlights.

### Light Theme
A complementary light appearance with suitable contrast and readable components.

## 5. Design Principles

1. Minimal and premium appearance.
2. One primary purpose per screen.
3. Generous spacing.
4. Clear visual hierarchy.
5. Avoid overcrowded interfaces.
6. Use progressive disclosure for advanced information.
7. Keep important actions visually clear.
8. Maintain consistent navigation.
9. Use readable charts and data visualisations.
10. Ensure mobile usability.

## 6. Component Guidelines

### Cards
Use rounded cards with subtle borders and clear content hierarchy.

### Buttons
Use electric green for primary actions and neutral surfaces for secondary actions.

### Forms
Keep forms short and divide complex registration processes into steps.

### Maps
Keep maps visually clear and use collapsible bottom sheets for additional information.

### Charts
Use simple, readable charts that communicate useful vehicle information without unnecessary complexity.

## 7. Navigation

The five primary navigation tabs are:

1. Home
2. Insights
3. Plan
4. Discover
5. Profile

## 8. Design Tools

Google Stitch is being used for UI exploration and screen design.

The final designs will serve as references during React Native implementation.
